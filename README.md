# uni-exam-sys

A university exam management system built with [Better-T-Stack](https://github.com/AmanVarshney01/create-better-t-stack), combining Next.js, Convex, and Clerk for a modern, type-safe, full-stack TypeScript experience.

## Features

- **TypeScript** - For type safety and improved developer experience
- **Next.js** - Full-stack React framework
- **TailwindCSS** - Utility-first CSS for rapid UI development
- **Shared UI package** - shadcn/ui primitives live in `packages/ui`
- **Convex** - Reactive backend-as-a-service platform
- **Authentication** - Clerk
- **Turborepo** - Optimized monorepo build system

## Prerequisites

This project uses [Bun](https://bun.sh) as its package manager and runtime. You also need a Convex account and a Clerk account (both have free tiers).

## Installation

### 1. Install Bun

Bun is required to install dependencies and run scripts. Install it using the official installer:

**macOS / Linux / WSL:**

```bash
curl -fsSL https://bun.sh/install | bash
```

**Windows (PowerShell):**

```powershell
powershell -c "irm bun.sh/install.ps1 | iex"
```

**npm (any platform):**

```bash
npm install -g bun
```

After installation, restart your terminal and verify Bun is installed:

```bash
bun --version
```

> If `bun` is not found after installing on macOS/Linux, add it to your PATH:
> ```bash
> echo 'export PATH="$HOME/.bun/bin:$PATH"' >> ~/.bashrc   # for bash
> echo 'export PATH="$HOME/.bun/bin:$PATH"' >> ~/.zshrc    # for zsh
> ```
> Then restart your terminal or run `source ~/.bashrc` / `source ~/.zshrc`.

### 2. Clone the repository

```bash
git clone <your-repo-url> uni-exam-sys
cd uni-exam-sys
```

### 3. Install dependencies

```bash
bun install
```

This installs dependencies for all workspaces (apps and packages) in the monorepo.

## Convex Setup

This project uses Convex as its backend. You'll need to set up a Convex project before running the app.

### 1. Create a Convex account

Sign up at [convex.dev](https://convex.dev) if you don't already have an account.

### 2. Run the setup script

```bash
bun run dev:setup
```

This runs `convex dev --configure --until-success` and walks you through:
- Logging into Convex
- Creating a new Convex project
- Linking it to this application

### 3. Copy environment variables

After the setup completes, Convex writes its environment variables to `packages/backend/.env.local`. Copy the relevant values into the app environments:

```bash
cp packages/backend/.env.local apps/web/.env
```

Open `apps/web/.env` and ensure the Convex-related variables are present (e.g. `CONVEX_DEPLOYMENT`, `NEXT_PUBLIC_CONVEX_URL`).

## Clerk Authentication Setup

Clerk handles authentication for the app and Convex.

### 1. Create a Clerk application

1. Sign up at [clerk.com](https://clerk.com) and create a new application.
2. From the Clerk Dashboard, copy:
   - The **Publishable key** (starts with `pk_test_...`)
   - The **Secret key** (starts with `sk_test_...`)

### 2. Configure Convex with Clerk

Follow the official guide to wire Clerk into Convex: [Convex + Clerk](https://docs.convex.dev/auth/clerk).

In short, you need to:

1. In the [Convex Dashboard](https://dashboard.convex.dev), go to your project's **Settings → Environment Variables**.
2. Add `CLERK_JWT_ISSUER_DOMAIN` and set it to your Clerk Frontend API URL (e.g. `https://your-app.clerk.accounts.dev`). Do **not** include a trailing slash.

### 3. Configure the web app

Create or update `apps/web/.env` with the following variables:

```env
# Convex
CONVEX_DEPLOYMENT=<your-convex-deployment>
NEXT_PUBLIC_CONVEX_URL=<your-convex-deployment-url>

# Clerk
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_test_xxxxxxxxxxxxxxxxxxxxx
CLERK_SECRET_KEY=sk_test_xxxxxxxxxxxxxxxxxxxxx
```

> Tip: `packages/backend/.env.local` is generated by the Convex setup and contains the Convex values. After copying them over, add the Clerk keys to the same `.env` file.

## Seed the Super Admin (optional)

If your project includes a super admin seed script, run it once Convex is configured:


## Running the Development Server

Start all apps (web + Convex backend) in development mode:

```bash
bun run dev
```

Or run them individually:

```bash
bun run dev:web    # Start only the Next.js web app (port 3001)
bun run dev:server # Start only the Convex backend
```

Open [http://localhost:3001](http://localhost:3001) in your browser to see the web application. Your app will connect to the Convex cloud backend automatically.

## UI Customization

React web apps in this stack share shadcn/ui primitives through `packages/ui`.

- Change design tokens and global styles in `packages/ui/src/styles/globals.css`
- Update shared primitives in `packages/ui/src/components/*`
- Adjust shadcn aliases or style config in `packages/ui/components.json` and `apps/web/components.json`

### Add more shared components

Run this from the project root to add more primitives to the shared UI package:

```bash
npx shadcn@latest add accordion dialog popover sheet table -c packages/ui
```

Import shared components like this:

```tsx
import { Button } from "@uni-exam-sys/ui/components/button";
```

### Add app-specific blocks

If you want to add app-specific blocks instead of shared primitives, run the shadcn CLI from `apps/web`:

```bash
npx shadcn@latest add <component>
```

## Troubleshooting

- **`bun: command not found`** - Bun isn't on your PATH. Re-run the installer and source your shell config (see step 1).
- **Convex setup keeps prompting** - Make sure you're logged in (`bunx convex login`) and have an active project.
- **Clerk auth not working in Convex** - Double-check `CLERK_JWT_ISSUER_DOMAIN` in the Convex Dashboard, and make sure there is no trailing slash.
- **Port 3001 in use** - Stop the conflicting process or change the port in `apps/web/package.json` (`next dev --port <port>`).
